citAI Nexus Backup

Private Google Drive backup application

citAI Nexus Backup is a private, owner-operated configuration of rclone, used to back up selected geospatial project files from a local computer to the owner's own Google Drive account.

How it works

After the account owner grants Google OAuth authorization, rclone transfers selected files directly from the local device to Google Drive. This website does not receive or store files, login credentials, or OAuth tokens.

Google Drive access

The application uses the drive.file permission to create and manage files associated with the backup application, without requesting unrestricted access to the user's Google Drive.

Authorization can be revoked in Google Account settings.

For further information, read the Privacy Policy.
